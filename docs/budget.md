# Budget Compilation

The `picomatch.budget()` entry point performs explicit budget checks before
generating an executable matcher. This prevents resource exhaustion and
catastrophic backtracking caused by pathological glob patterns.

## Usage

```js
const picomatch = require('picomatch');

// Passes budget checks, returns a matcher identical to picomatch().
const isMatch = picomatch.budget('@(a|b)', { maxDepth: 2 });
console.log(isMatch('a')); //=> true

// Throws BudgetError before generating a matcher.
picomatch.budget('@(a|@(b|c))', { maxDepth: 1 });
//=> BudgetError: Extglob nesting depth 2 exceeds maximum allowed depth 1
```

## Budget Definitions

Three independent budgets are checked. A pattern is rejected if it exceeds
**any** of them.

### 1. `maxBranches` — Actual Branch Count

The total number of actual branches across all extglobs and braces.

- **Extglobs**: each `|` separator at the extglob's top level adds a branch.
  An extglob with N separators has N+1 branches.
- **Comma braces**: each `,` separator at the brace's top level adds a branch.
  A brace with N commas has N+1 branches.
- **Range braces** (`{a..z}`): do **not** add branches. They expand to a
  single character class (e.g. `[a-z]`), regardless of the range span.
- **Excluded**: escaped pipes (`\|`), pipes inside character classes (`[a|b]`),
  and pipes inside nested groups are not counted.

**Default**: `25`

**Example**:
```js
// `@(a|b|c)` has 3 branches.
picomatch.budget('@(a|b|c)', { maxBranches: 3 }); // OK
picomatch.budget('@(a|b|c)', { maxBranches: 2 }); // BudgetError
```

### 2. `maxDepth` — Nested Extglob Depth

The maximum nesting depth of extglobs (`@(`, `+(`, `*(`, `?(`, `!(`).

- The outermost extglob is depth 1.
- Each nested extglob adds one level.
- **Excluded**: escaped parentheses (`\(`), parentheses inside character
  classes (`[(]`), and regular (non-extglob) parentheses do not count.

**Default**: `3`

**Example**:
```js
// `@(a|@(b|c))` has depth 2.
picomatch.budget('@(a|@(b|c))', { maxDepth: 2 }); // OK
picomatch.budget('@(a|@(b|c))', { maxDepth: 1 }); // BudgetError
```

### 3. `maxRegexLength` — Generated Regex Length

The length of the regex source string generated by picomatch's parser.

- This is the actual output of `picomatch.parse(pattern).output.length`.
- It reflects the true cost of the pattern, including brace expansion.
- Range braces contribute their actual expansion length (a character class),
  not the raw pattern length.

**Default**: `2000`

**Example**:
```js
// A long pattern generates a long regex.
picomatch.budget('a'.repeat(100), { maxRegexLength: 50 }); // BudgetError
```

## Error Reporting

When a budget is exceeded, a `BudgetError` is thrown with a `details` object:

```js
{
  budget: 'depth',        // Which budget was exceeded: 'branches' | 'depth' | 'regexLength'
  actual: 2,              // The actual value
  limit: 1,               // The configured limit
  range: [4, 9],          // Source range [start, end] in the original pattern
  source: '@(a|@(b|c))'   // The original pattern
}
```

The `range` field identifies the exact source interval that caused the
over-limit. For depth and branch budgets, this is the specific extglob or
brace. For regex length, this is the entire pattern.

## Brace Expansion Estimation

Range braces (`{a..z}`) are estimated by their **actual expansion rules**,
not by raw character counting:

- **Default expansion**: picomatch sorts the endpoints and emits a single
  character class (e.g. `[a-z]`). The cost is the length of this class.
- **Custom expansion** (`options.expandRange`): the custom function is called
  with the endpoints, and the cost is the length of its result.

A range brace is **one construct**, regardless of the range span. `{a..z}`
and `{a..c}` both produce a single character class and contribute zero
branches.

## API

### `picomatch.budget(pattern, options)`

Compile a matcher with budget checks. Returns a matcher function identical
to `picomatch(pattern, options)` if all budgets pass.

### `picomatch.budget.analyze(pattern, options)`

Analyze a pattern without compiling. Returns a budget profile:

```js
{
  input: '@(a|@(b|c))',
  regexLength: 9,
  output: '(a|(b|c))',
  totalBranches: 4,
  maxDepth: 2,
  extglobs: [{ type, extglobType, start, end, depth, branches, branchCount }],
  braces: [{ type, start, end, commas, isRange, branches, cost }]
}
```

### `picomatch.budget.BudgetError`

Error class thrown when a budget is exceeded.

### Default Values

- `picomatch.budget.DEFAULT_MAX_BRANCHES` = 25
- `picomatch.budget.DEFAULT_MAX_DEPTH` = 3
- `picomatch.budget.DEFAULT_MAX_REGEX_LENGTH` = 2000
